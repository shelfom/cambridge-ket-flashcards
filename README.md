# Cambridge KET Flashcards

An illustrated Group A pilot for elementary learners, based on the official August 2025 Cambridge A2 Key and A2 Key for Schools Vocabulary List.

## What is included

- All 98 A entries, from `a/an` to `awful`
- One storybook picture clue on every front
- One fixed, loud, natural British-female neural headword recording
- One or two short Chinese glosses
- One 3–8-word plain-English meaning
- One short example sentence
- Fixed, zero-scroll AWL-style practice flow with saved progress

## Local use

```bash
npm install
npm test
npm run dev
```

The Cambridge word list is the source for entry selection and the nine complete official examples noted in the data. This is an unofficial learning aid and is not endorsed by Cambridge.
